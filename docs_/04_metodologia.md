4. Metodología
   
4.1 Tipo de investigación

La presente investigación es de tipo aplicada, ya que busca utilizar los conocimientos adquiridos en el curso de Herramientas de Desarrollo para crear una solución tecnológica frente a una problemática real. En este caso, se desarrolla AdoptaAmigo, una plataforma web orientada a facilitar la adopción de mascotas y apoyar en la búsqueda de mascotas perdidas.
El proyecto aplica conocimientos relacionados con el desarrollo de software, organización del código y control de versiones. Además, se consideran las diferentes etapas del desarrollo de software, como la planificación, diseño, codificación, pruebas e implementación, las cuales permiten construir una solución funcional y orientada a las necesidades de los usuarios.

4.2 Técnicas

Para obtener la información necesaria y comprobar el funcionamiento de la solución se emplearon técnicas de observación, recopilación de información y pruebas funcionales.
La observación permitió identificar las principales necesidades relacionadas con la búsqueda y publicación de mascotas. A partir de ello, se determinaron funcionalidades como la publicación de mascotas en adopción y la visualización de mascotas perdidas mediante fotografías, información de contacto y recompensa ofrecida.
También se realizó la recopilación de información para establecer los datos que debe contener cada publicación. Finalmente, mediante pruebas funcionales se verificó que las características desarrolladas cumplieran con lo planteado y que el sistema pudiera ser utilizado de manera adecuada.

4.3 Materiales

Para el desarrollo de AdoptaAmigo se utilizaron recursos tecnológicos y de apoyo necesarios para la elaboración de la plataforma. Entre ellos se encuentra una computadora o laptop, conexión a Internet, editor de código, archivos del proyecto, imágenes e información de las mascotas y los diseños realizados previamente para definir la estructura de la plataforma.
También se utilizaron recursos relacionados con el desarrollo colaborativo, principalmente el repositorio del proyecto, donde se almacena el código y los avances realizados por los integrantes.

4.4 Instrumentos

Los principales instrumentos utilizados fueron la ficha de requerimientos, lista de pruebas, Git y GitHub.
La ficha de requerimientos permitió organizar las necesidades y funcionalidades que debía cumplir AdoptaAmigo. La lista de pruebas permitió comprobar características como la visualización de mascotas en adopción, consulta de información, fotografías y publicaciones de mascotas perdidas.
Asimismo, se utilizó Git como herramienta de control de versiones para registrar los cambios realizados en el código. Los cambios fueron almacenados mediante commits, permitiendo mantener un historial del desarrollo. El uso de ramas permitió que los integrantes trabajaran de manera independiente en diferentes partes del proyecto.
Por otro lado, GitHub fue utilizado como repositorio remoto para almacenar y compartir el código del proyecto. Los cambios desarrollados en las diferentes ramas fueron integrados mediante merge. En caso de presentarse modificaciones incompatibles, se realizó la identificación y resolución de conflictos antes de integrar los cambios a la rama principal.
Estas herramientas se relacionan directamente con los contenidos desarrollados en clase sobre control de versiones, ya que permiten mantener el código organizado, registrar modificaciones y facilitar el trabajo colaborativo.

4.5 Procedimiento metodológico

El desarrollo de AdoptaAmigo se realizó considerando las principales etapas del proceso de desarrollo de software: planificación, diseño, codificación, pruebas e implementación. Estas etapas permiten organizar el desarrollo desde la identificación de los requisitos hasta la obtención de una solución funcional.
En la planificación, se identificó la problemática y se determinaron las principales funciones de la plataforma. En el diseño, se definió la estructura de las interfaces y la forma en que se presentaría la información de las mascotas.
Durante la codificación, se desarrollaron las funcionalidades de AdoptaAmigo y se utilizó Git para registrar los avances. Cada integrante pudo trabajar mediante ramas y guardar sus modificaciones mediante commits.
Posteriormente, en la etapa de pruebas, se verificó el funcionamiento de las características principales y se corrigieron los errores encontrados. Finalmente, se realizó la integración de los diferentes aportes mediante merge, obteniendo una versión conjunta del proyecto.
El uso de un enfoque organizado y colaborativo resulta adecuado para el proyecto, debido a que las metodologías de desarrollo actuales buscan facilitar la colaboración, adaptarse a cambios y realizar entregas de manera progresiva.

4.6 Sustento de la metodología

La metodología empleada permite relacionar los conocimientos teóricos del curso con la construcción de una solución tecnológica real. El proceso de desarrollo permite organizar las actividades desde la identificación de los requisitos hasta las pruebas de la plataforma, mientras que el control de versiones permite administrar los cambios realizados durante el proyecto.
El uso de Git y GitHub es especialmente importante para el trabajo colaborativo, debido a que permite mantener un historial de modificaciones, trabajar mediante ramas y posteriormente integrar los aportes de los integrantes. De esta manera, el equipo puede desarrollar diferentes funcionalidades sin afectar directamente la versión principal del proyecto.
Por ello, la metodología seleccionada resulta adecuada para AdoptaAmigo, ya que permite desarrollar la plataforma de manera ordenada, controlar los cambios del código y comprobar que las funcionalidades propuestas respondan al objetivo del proyecto.
