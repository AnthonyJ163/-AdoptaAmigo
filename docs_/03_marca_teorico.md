3. Marco Teórico
3.1 Estado del arte
Actualmente, las herramientas digitales permiten desarrollar plataformas que facilitan el acceso y la organización de información. En el caso de la adopción de mascotas, las publicaciones suelen encontrarse en redes sociales, grupos o diferentes páginas, lo que puede dificultar encontrar información completa sobre los animales disponibles.
Las plataformas digitales pueden ayudar a centralizar esta información y presentarla de una manera más ordenada. Además, permiten que los usuarios puedan consultar información sobre las mascotas y conocer cuáles se encuentran disponibles para adopción.
En este contexto surge AdoptaAmigo, una propuesta de plataforma digital orientada a facilitar la búsqueda de mascotas que necesitan un hogar. El sistema busca presentar la información de forma sencilla y permitir una mejor interacción entre las personas interesadas en adoptar y quienes publican a las mascotas.
3.2 Teoría
3.2.1 Control de versiones
El control de versiones es un sistema que permite registrar y administrar los cambios realizados en un proyecto de software. Su función principal es mantener un historial de las modificaciones realizadas en los archivos.
Esta herramienta es especialmente importante cuando un proyecto es desarrollado por varias personas, ya que permite identificar los cambios realizados y facilita la recuperación de versiones anteriores en caso de algún problema.
En AdoptaAmigo, el control de versiones permitirá mantener organizados los diferentes avances del proyecto y facilitar el trabajo colaborativo entre los integrantes del equipo.
3.2.2 Repositorios
Un repositorio es un espacio donde se almacenan los archivos y el código de un proyecto. También permite conservar el historial de cambios realizados durante su desarrollo.
Los repositorios pueden ser locales, cuando se encuentran almacenados en el equipo del desarrollador, o remotos, cuando se encuentran almacenados en una plataforma en línea.
En el proyecto AdoptaAmigo, el repositorio permitirá almacenar el código, archivos, recursos y demás elementos necesarios para el desarrollo de la plataforma.
3.2.3 Ramas o Branches
Las ramas, conocidas como branches, permiten crear diferentes líneas de trabajo dentro de un mismo repositorio. Su finalidad es que los desarrolladores puedan trabajar en nuevas funcionalidades o realizar modificaciones sin afectar directamente la versión principal.
Por ejemplo, una rama puede utilizarse para desarrollar el registro de mascotas y otra para trabajar en el diseño de la interfaz.
En AdoptaAmigo, se utilizará la rama main como referencia de la versión principal del proyecto. También se pueden crear ramas adicionales para desarrollar funcionalidades específicas y posteriormente integrarlas.
3.2.4 Commits
Un commit es un registro de los cambios realizados en un proyecto. Cada commit puede incluir un mensaje que describa brevemente qué se modificó.
Los commits permiten mantener un historial ordenado del desarrollo y conocer los diferentes avances realizados por los integrantes del equipo.
En AdoptaAmigo, los commits se realizarán después de completar cambios importantes. Por ejemplo:
Agregar formulario de registro de mascotas
Actualizar página principal
Corregir diseño de tarjetas
De esta manera, los mensajes permitirán identificar fácilmente qué se realizó en cada avance.
3.2.5 Merge
El merge es el proceso mediante el cual se integran los cambios de una rama con otra. Generalmente, se utiliza para incorporar una funcionalidad desarrollada en una rama secundaria a la rama principal.
Durante el desarrollo de un proyecto pueden existir diferentes ramas creadas por los integrantes. Una vez que una funcionalidad está terminada y revisada, sus cambios pueden integrarse mediante un merge.
En AdoptaAmigo, el merge permitirá unir el trabajo desarrollado por los diferentes integrantes para mantener una versión completa del proyecto.
3.2.6 Resolución de conflictos
Un conflicto puede aparecer cuando dos integrantes modifican la misma parte de un archivo de diferentes maneras. Git detecta esta situación y solicita que se revise cuál de los cambios debe mantenerse.
La resolución de conflictos consiste en revisar las modificaciones, elegir la opción correcta o combinar los cambios y posteriormente guardar el archivo para continuar con el proceso.
En AdoptaAmigo, la resolución de conflictos será importante para evitar que el trabajo de un integrante sobrescriba accidentalmente el trabajo realizado por otro.
3.2.7 Git y GitHub
Git es un sistema de control de versiones utilizado para registrar y administrar los cambios de un proyecto. Permite trabajar con ramas, realizar commits y mantener un historial de las modificaciones.
GitHub es una plataforma que permite almacenar repositorios de Git de manera remota y facilita el trabajo colaborativo entre diferentes integrantes.
Durante el desarrollo de AdoptaAmigo, Git y GitHub permitirán organizar el código y compartir los avances del proyecto.
Entre los comandos básicos que pueden utilizarse se encuentran:
git clone: permite descargar una copia del repositorio.
git add: prepara los archivos modificados.
git commit: registra los cambios realizados.
git push: envía los cambios al repositorio remoto.
git pull: obtiene los cambios existentes en el repositorio remoto.
 
3.3 Conceptos claves
Adopción: Proceso mediante el cual una mascota encuentra un nuevo hogar.
Mascota perdida: Animal que se ha extraviado y busca ser encontrado.
Publicación: Registro con información y fotografía de una mascota.
Recompensa: Monto ofrecido por ayudar a encontrar una mascota perdida.
Plataforma digital: Espacio web donde se organiza y comparte información.
Sistema web: Aplicación que funciona mediante un navegador.
Control de versiones: Permite registrar y controlar los cambios realizados en el proyecto.
Repositorio: Espacio donde se almacena el código del proyecto.
Branch: Rama que permite trabajar en una parte del proyecto sin afectar la principal.
Commit: Registro de los cambios realizados.
Merge: Unión de cambios realizados en diferentes ramas.
Conflicto: Ocurre cuando existen cambios incompatibles entre ramas.
Git: Herramienta utilizada para controlar las versiones del código.
GitHub: Plataforma donde se almacenan y gestionan repositorios Git.
